# Hardware Control 

The hardware control software/ device adapter classes in this repository were developed during my PhD project in the Lab of Knut Drescher at the Philipps-Universität Marburg and the Biozentrum, University of Basel.

## Citation

If you use the software in your work, please cite the associated thesis:

```
Neuhaus, K. (2026). Novel microscopy-based approaches to study bacterial communities.
PhD thesis, Philipps-Universität Marburg.
```
